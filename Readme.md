# To-DoListApp

A simple client-side To-Do List web app built with HTML, CSS and JavaScript.

## Features 

- Add, remove, and mark tasks as completed
- Persistent data in browser (localStorage)
- Responsive layout for desktop and mobile

## Files

- `index.html` — app markup
- `style.css` — styles
- `script.js` — app logic
- `To-Do-Img/` — image assets

## Installation

No build step required. Open `index.html` in your browser to run the app locally.

## Usage

1. Open the app in a browser.
2. Type a task into the input and press the add button or Enter.
3. Click a task to toggle completion; use remove to delete.

## Development

- Edit `script.js` and `style.css` to change behavior or appearance.
- Use your editor's live server or open `index.html` directly.
